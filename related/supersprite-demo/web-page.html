SuperSprite 데모

애플2 PC 이미지에 들어갈 LinApple 코어를 그대로 브라우저용으로 빌드했어요. 공 8개는 TMS9918A 스프라이트이고, 그 아래 글자는 애플 //e의 텍스트 화면입니다.

에뮬레이터 불러오는 중…

키보드가 있으면 화면을 한 번 누른 뒤 스페이스·M·S를 직접 눌러도 돼요. 소리는 브라우저 정책상 버튼을 눌러야 나옵니다.

화면에서 확인할 것

  • SPACE를 누르면 애플 영상 입력이 꺼져 VDP의 투명한 부분이 검게 바뀌어요. 공과 위아래 무지개 띠만 남습니다.
  • M을 누르면 VDP 화면이 빠지고 애플 화면만 나와요. 다시 누르면 합성으로 돌아옵니다.
  • 공이 벽에 부딪칠 때마다 AY-3-8912가 공 번호마다 다른 음높이로 짧게 울려요.

카드 I/O 주소 (슬롯 7)

주소기능
$C0F0VDP VRAM 읽기·쓰기 (주소 자동 증가)
$C0F1VDP 상태 읽기 / 주소·레지스터 쓰기
$C0F2Echo II 음성 (미구현, 항상 대기 상태)
$C0F3 · $C0F4애플 영상 입력 끔 · 켬
$C0F5 · $C0F6애플 화면만 · VDP 합성 출력
$C0FC · $C0FDAY 데이터 쓰기
$C0FE · $C0FFAY 레지스터 선택 / 데이터 읽기

데모는 6502 어셈블리 1KB짜리로, VDP 프레임 플래그($C0F1 비트 7)를 기다려 초당 60번 스프라이트를 옮깁니다. 이 웹판에는 디스크 카드가 빠져 있어요.
